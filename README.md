# WeatherApp – moduł stylów (styles.css)

Aplikacja webowa do podglądu bieżącej temperatury, prognozy pogody, wilgotności oraz prędkości wiatru.

## Technologie
* HTML5
* CSS3 (Flexbox / Grid)
* JavaScript

## Mój wkład w projekt
Przygotowanie pliku `styles.css` – układ dashboardu, stylizacja paska bocznego, kafelków pogodowych oraz responsywność (RWD).

## Uruchomienie
1. Pobierz lub sklonuj repozytorium.
2. Otwórz plik `index.html` w dowolnej przeglądarce.
